# Screenshots

The repo has a `screenshots/` folder ready for tagged images.

What would be most useful:

| File name | What it should show |
|---|---|
| `main.png` | The connected header + Dashboard tab (band, CQI/MCS, signal history) |
| `scanner.png` | Cell Scanner with a completed scan and the camped cell highlighted |
| `sweep.png` | Sweep All Bands mid-run, progress bar + per-band DL Mbps |
| `optimiser.png` | Optimiser results table (Band / PCI / DL Mbps) |
| `antennas.png` | Antenna Combo sweep ranking |
| `log.png` | The Log tab with a full sweep history |

For privacy, please **blur or mock the SIM number, phone numbers and your
exact network name** in any screenshot before opening a PR. Signal values are
fine as-is.

If you open a pull request after adding screenshots under `screenshots/`,
the README's screenshot section will be updated to display them.
